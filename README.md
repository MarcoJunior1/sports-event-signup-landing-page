# 🏐 Vôlei Sem Limites

Site com visual **futurista** para um projeto/evento de vôlei, com galeria de "momentos épicos" e **formulário de inscrição**.

## ✨ Funcionalidades

- Página inicial com chamada "Participe Agora"
- Galeria de imagens de vôlei
- Página de **inscrição** (`formulario.html`)

## 🗂️ Estrutura

```
├── index.html
├── formulario.html
├── style.css
└── (imagens)
```

## 🛠️ Tecnologias

HTML · CSS

## 🚀 Como usar

Abra `index.html` no navegador.
